# 历法口径

历法口径版本：calendar-v1（规则引擎 v2 沿用）。默认所有时间换算至北京时间 UTC+8（固定时区），不随服务器时区改变，不进行出生地经度、夏令时或真太阳时校正。

- 使用 lunar-python 1.4.8 的 Solar → Lunar → EightChar，立春的准确交节时刻换年，十二个“节”的准确交节时刻换月。与春节换年、农历初一换月不同。
- 默认 sect=2，日柱在民用日 00:00 换日。配置 zi 改用 sect=1，23:00 子初换日。时柱两种设置都遵循库的五鼠遁：晚子时 23:00–23:59 的时干按次日日干推导，因此零点换日口径下，晚子时的日干与用来起时干的日干可能不同。这是已声明的流派约定。
- 时辰是两小时区间，右端不包含；子时 23:00–01:00。当前公历时间显示到小时，并同时显示年、月、日、时四柱。内部保留分秒以判定交节边界。
- 生日默认且只接受阳历 YYYYMMDD 或 YYYY-MM-DD。只有日期时用中午确定日柱；不生成出生时柱，也不把当前时辰当出生时辰。
- 支持 1900–2100 年的换算；生日还必须不晚于当天。日柱必须属于六十甲子；“甲丑”等阴阳错配值拒绝。
- 临时生日/日柱优先于已绑定资料，但不写回绑定。绑定只保存当前发送人的资料。

历法来源：[香港天文台：天干和地支](https://www.hko.gov.hk/tc/gts/time/stemsandbranches.htm)、[lunar-python 官方仓库](https://github.com/6tail/lunar-python)、[lunar 官方 API](https://6tail.cn/calendar/api.html)。天文台用于干支和时辰基础说明；换年换月与晚子时的具体实现以本插件锁定库版本及以上约定为准。
