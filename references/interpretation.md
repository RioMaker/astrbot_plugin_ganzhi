# 五行与日主结果阅读说明

版本：ganzhi-rules-v2。完整研读笔记在 `references/bazi_notes.md`，来源和规则编号在 `data/rule_sources.json`；两者都会随 Agent 工具结果返回。

## 与 v1 的变化

删除年/月/日固定权重、藏干数值比例、季节乘数、环境百分比与 10% 流通阈值。现在直接返回月令、透藏、根气、位置、生克泄关系、合冲刑害及制化候选条件。这些是传统模型中的结构证据，不是测得的五行能量。

`day_flow` 只用当前年/月/日，`current_flow` 另加当前时柱，`hour_flow` 单列时柱。三者都是环境，不能作为用户本命。辰戌丑未月的逐日司令保持未判。

## 状态语义

- `observed`：表项或生克关系出现。
- `candidate`：满足本插件声明的基础筛选条件，仍未证实实际制化力量。
- `conditional`：存在候选但有未满足条件；`checks` 为真表示该条件满足，为假表示尚不满足或有干扰；`issues` 列的是需要补足/复核的条件。
- `hidden_only` / `missing`：中介只暗藏 / 未见。
- 三合、三会、三刑的 `complete` 只表示三支齐全；`complete_with_conflict` 另有冲刑，`partial` 必须查看缺支。
- `transformed` / `resolved` 始终为 false；不修改原字五行、不消除原克边、不判化气格。

## 十神与宜忌

以用户日干为我，同五行分比肩/劫财；我生分食神/伤官；我克分偏财/正财；克我分七杀/正官；生我分偏印/正印，每对前者同阴阳、后者异阴阳。概念参考[《三命通会》卷五·论古人立印食官财名义](https://zh.wikisource.org/wiki/三命通會/卷五)。

`relations_evidence` 将今日环境的五行证据映射成生我、同我、我生、我克、克我，通过 `evidence_ref` 指向透藏位置，不代表用户出生时的根气。`season_state` 只是当前月份背景。生日只取日柱，不补造其他出生柱；不计算本命强弱、用神、大运或吉凶分数。

现代活动建议仍使用 `data/ten_gods.json`：普通命令显示今日/此刻各一宜一忌，Agent 获得全部建议与详细解释。它们不是古籍原文或黄历择日表，不随某个制化候选就自动改判为吉凶。

## 图片与 Agent

图片保持天干、地支、完整藏干上下排布。横向画相邻柱，纵向画同柱天干与地支本气，箭头标基础生克；合冲刑害仅显示少量短提示，完整列表及位置在 `current_flow`。箭头不表示生克已取得作用效果。

Agent 应先说明原始干支和观察范围，再依序说明月令与根气、实际关系、候选条件和不足，最后给简短活动建议。日报覆盖十天干，不能引用任何群员生日。不要把候选写成已化、把冲写成必有灾，也不要重算覆盖历法或另造好运评分。
