# ganzhi · 干支纪时与日主日运

AstrBot 插件 `astrbot_plugin_ganzhi`，提供当前四柱图片、阳历生日/日柱绑定、当日五行流通、日主作用与当前时辰宜忌，以及按群开关的 AI 日报。当前版本 0.2.0，声明支持 AstrBot >=4.24.0、OneBot v11 / aiocqhttp。

图片采用每柱“天干在上、地支在下”，其下列出完整藏干及五行。绿色箭头表示生、粉色箭头表示克，虚线双箭头表示同气；横向连接相邻柱，纵向对照天干与地支本气。短标签列出当前四柱的干合及支合冲害，干合标记“未定化”。保留一句五行概况和今日/此刻各一宜一忌；十日主日报保持紧凑表格。完整参考及关系图数据同步交给 Agent。

0.2.0 依据《三命通会》《滴天髓阐微》《渊海子平》的相关章节重写五行规则：去除固定权重、百分比和 10% 流通阈值，改用月令、透藏、根气、位置与逐项条件。新增通关/制约/合化候选、争合、刑、三合与三会；每项可追溯到研读笔记和来源。

## 使用

| 指令 | 行为 |
| --- | --- |
| `/干支` | 当前四柱图片，精确到小时；已绑定时自动附个人日运及当前时辰宜忌 |
| `/干支 辛巳` | 临时指定日柱分析，不覆盖绑定 |
| `/干支 辛` | 只知道日主时也可使用 |
| `/干支 20010319` | 临时按阳历生日分析；也支持 `2001-03-19` |
| `/干支 绑定 20010319` | 绑定自己的阳历生日，换算日柱 |
| `/干支 绑定 辛巳` | 直接绑定自己的日柱；也支持单个日主 |
| `/干支 我的` | 查看绑定类型与日柱，不在群内回显完整生日 |
| `/干支 解绑` | 删除自己的绑定 |
| `/干支 help` | 完整帮助 |
| `/干支日报 开`、`/干支日报 关` | 群主、群管理员或 AstrBot 管理员设置当前群 |
| `/干支日报 状态` | 查看当前群日报状态 |

`/干支纪年法`、`/干支纪时法` 与 `/干支` **完全等价**，包含所有子命令，如 `/干支纪时法 绑定 辛巳`、`/干支纪年法 日报 开`。还支持 `/干支 日报 开|关|状态` 和两种全称加“日报”的入口。

生日**默认且只接受阳历**。只有日期时只取得日柱，不虚构出生时柱；不支持把农历生日直接当阳历输入。1900 年以前、未来生日、无效日期、非六十甲子的日柱都会拒绝。临时资料优先于绑定，临时查询不写回。

## 安装

把安装包解压出的 `astrbot_plugin_ganzhi` 放进 AstrBot 的 `data/plugins/`，在 AstrBot 环境安装 `requirements.txt` 后重启或重载插件。也可使用 AstrBot 的本地 ZIP 插件安装功能。需要 Python >=3.10。

内置约 300 KB 的 OFL 中文字体，图片使用 Pillow 离线生成，不需要浏览器或外部截图服务；图片渲染不可用时返回文字。`metadata.yaml` 的 `repo` 留空：当前只有本地项目，未建立远程仓库或发布市场。

## AI 调用

- `ganzhi_analyze(profile="", send_image=true)`：查当前时间，优先读取当前用户的绑定；也可传阳历生日、日柱或单个日干。返回结构化四柱、五行透藏与通根证据、生克泄关系、制化候选及逐项条件、十神、支关系、宜忌、研读笔记和规则来源目录。默认先向当前会话发简明图片，Agent 随后根据返回内容解读。
- `ganzhi_profile(action="view|bind|unbind", profile="...")`：仅管理当前发送人的资料；工具说明要求用户明确提出保存或删除时才执行写操作。

对话示例：“按我绑定的日主看一下今天和现在这个时辰适合做什么。”“我的阳历生日是 2001 年 3 月 19 日，帮我绑定。”

普通命令采用规则简报，不额外消耗 LLM；AI 间接调用由 AstrBot 原本的 Agent 流程执行。没有注册全消息监听或额外唤醒规则。

## 日报

各群默认关闭，北京时间 **08:00** 发送。内容包含公共干支状态、五行流通和甲乙丙丁戊己庚辛壬癸十日主的简明宜忌，不读取任何人的绑定资料。默认调用当前群配置的 AstrBot 模型撰写解读，另附完整规则图片；无模型、超时、异常或输出为空/过长时使用规则简报。

WebUI 可配置时间、模型 ID、AI 开关和超时。`daily_use_ai` 只决定启用群的解读方式，**不会打开任何群的订阅**。设定时间支持 `HH:MM`，更改后重载。权限来源为 AstrBot 管理员标记或 OneBot 的群成员角色；角色缺失时进行一次带 8 秒超时的 `get_group_member_info` 查询。

每 30 秒检查一次，默认允许计划时间后 30 分钟内补发，超过窗口等次日。订阅以平台实例+群隔离，即使 AstrBot 开启群成员独立会话也只有一份群订阅。保存成功日期，重启、开关切换及重复扫描不会主动重复已记录成功的日报。失败最多尝试 3 次，间隔至少 5 分钟。AI 生成期间关掉日报，会在发送前再次核对开关；插件卸载/重载会取消自己的调度任务。

网络发送和 KV 写入并非跨系统事务：消息已经发出但网络超时、或记录成功前进程崩溃时，后续重试仍可能重复。这不承诺端到端 exactly-once；日志仅记录异常类别，不记录生日或模型提示全文。多进程同时加载同一插件共享数据库也不在本版本支持范围。

## 计算口径与参考

默认北京时间 UTC+8，**立春准确时刻换年、节气准确时刻换月、零点换日**。时辰为两小时区间。可把 `day_boundary` 改为 `zi` 使用 23:00 子初换日；晚子时起时干采用 lunar-python 的既定流派实现，详见[历法口径](references/calendar.md)。不做真太阳时或出生地校正。

年/月/日三柱描述整日环境（`day_flow`），当前四柱补充时辰引入的作用（`current_flow`），单时柱为 `hour_flow`。包含根气、透藏、位置、生克泄、通关与制约候选、干合条件、支合冲刑害、三合与三会。辰戌丑未的逐日司令保留未判。候选不是已制住、已通关或已合化；不会由日柱推断完整本命的强弱、用神或大运。现代宜忌仍为原有十神主题建议。

**Agent 结果变更**：规则版本升级为 `ganzhi-rules-v2`；移除 `percent`、`raw`、`dominant`、`low`、`weak_paths`、`relations_percent`。改读 `elements`、`columns[].roots`、`relations`、`mechanisms`、`stem_combinations`、`branch_groups` 及个人 `relations_evidence`；后者的 `evidence_ref` 指向同一结果中的 `day_flow.elements`，避免重复传输。绑定/群订阅存储与命令保持兼容。

- [八字研读笔记](references/bazi_notes.md)：原典章节、分歧、WX01–WX12 规则与工程约定。
- [规则来源目录](data/rule_sources.json)：Agent 可按 `rule_ids` 查来源。
- [结果阅读文档](references/interpretation.md)：Agent 每次调用可直接获得，无需自行读文件。
- [十神简明宜忌和详细参考](data/ten_gods.json)：普通指令和 Agent 使用同一份内容。
- [第三方来源与许可](THIRD_PARTY_NOTICES.md)：历法、字体与参考原典来源。

这是传统文化语境的日常安排参考；结构规则不等于现实预测效果。阅读限于相关章节，原典录文存在讹字及不同口径，详见研读笔记。

## 数据与维护

绑定存储在 AstrBot 的插件 KV 中，以平台实例 ID+发送人 ID 的哈希为键；同一平台实例跨群可使用自己的绑定，不同用户或实例相互隔离。生日以规范化阳历日期保存，用户可解绑删除；群图片与模型分析结果只携带换算日柱，不返回生日原日期。插件运行时不向代码目录写图片和用户资料。

`calendar_core.py` 负责历法和校验，`wuxing.py` 负责生克制化证据，`engine.py` 负责日主映射、报告与 Agent 笔记载荷，`renderer.py` 负责图片，`scheduler.py` 负责调度，`main.py` 仅处理 AstrBot 接口和持久化。

本地开发验证：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q
.venv\Scripts\ruff check .
.venv\Scripts\ruff format --check .
.venv\Scripts\python scripts\preview.py
```

预览在 `.dev/previews/`。字体构建脚本 `scripts/build_font.py --source <原始OFL字体路径>` 会保留源码显示字符并重命名字体，改变展示文案后重建字体并检验字符覆盖。测试包括历法固定例、交节与子时、输入校验、十神、权限与绑定隔离、调度去重/取消和真实 PNG 渲染。AstrBot 适配层使用测试替身；QQ 实际收图、真实 Agent 调用与定时推送需要在部署环境验收。
